# DeckRef 交互方式说明

本文档描述 DeckRef 当前支持的所有交互方式，便于开发与使用时的统一理解。**开发时请优先查阅并维护本文档**，再修改交互逻辑。

**适用平台**：Mac / Windows 桌面端（鼠标、触控板、滚轮）。

**窗口与画布**：chuangkou（窗口）尺寸、画布空间与屏幕空间区分、各模式下的 Zoom / Transform / Resize 逻辑详见 **[CHUANGKOU_CANVAS_INTERACTION.md](CHUANGKOU_CANVAS_INTERACTION.md)**。

## 零、窗口与启动

- **窗口尺寸与位置记忆**：关闭窗口时会记录当前窗口的**位置**（外框左上角）和**内尺寸**；下次启动时按相同位置与尺寸打开，无需每次重新调整。
  - **显示器**：通过保存位置实现「记住哪台显示器」——系统会根据该坐标把窗口放到包含该点的显示器上；多屏时窗口会回到上次所在的那块屏。
  - 若从未保存过或文件无效，则使用默认尺寸（360×240），位置由系统决定。
  - 尺寸约束在约 200～3840（宽）、150～2160（高）；位置约束在合理范围内，避免异常恢复。
- **最小尺寸限制**：窗口不允许被拖拽到比 **200×150**（内容区）更小，保证工具栏与操作区域可用。

## 一、鼠标 / 触控板

以下交互以鼠标为主，触控板通常映射为相同行为（左键=主键，双指滚动=滚轮）。

### 1. 悬停（Hover）

- **操作**：将指针悬停在某张卡片上。
- **效果**：该卡片会轻微放大（约 1.08 倍），带有平滑动画；不改变顺序与位置。
- **说明**：命中检测按从最前到最后的顺序，仅最上层卡片响应悬停。

### 2. 视角平移（Pan）

- **操作**：按住**鼠标中键**并拖动。
- **效果**：整个堆叠区域随指针移动，实现画布平移。默认：拖动方向与内容移动方向一致（拖右则内容向右）。
- **说明**：若感觉方向相反，可在**设置**（右上角齿轮）中勾选「反转平移方向」。

### 3. 窗口移动（右键拖动）

- **操作**：按住**鼠标右键**并**拖动**（需拖动超过约 **4 像素** 才视为移动窗口，避免与右键菜单冲突）；仅点一下不移动不会触发。
- **效果**：超过阈值后窗口随指针移动。**Windows**（有窗口句柄时）：通过 **SendInput 注入左键按下** → 发送 WM_SYSCOMMAND SC_MOVE，由系统进入“拖标题栏”模态循环，主线程阻塞；后台线程在检测到**右键松开**时注入**左键松开**，系统结束拖动。由系统接管移动，无抖动。无 hwnd 或非 Windows 时仍由应用每帧 OuterPosition。
- **说明**：思路参考 PureRef（Move window threshold）；与中键（视角平移）、左键（拿起/点击）互不冲突。

**右键点击（未拖动或未超阈值）**：  
- **在图片上右键**（0.3.0 Phase 4）：弹出上下文菜单，本期含「用系统默认程序打开」「置顶」「复制路径」「复制图片」「加入组/从组移除」「移到最前/移到最后」；菜单结构可扩展。  
- **在空白处右键**（0.4.0）：弹出画布级上下文菜单，本期含「粘贴」「刷新」「新建便签」；菜单结构可扩展。  
详见 `docs/PRODUCT_ROADMAP_0.3.md` 第 3.2.1 节。

### 4. 缩放视图（View zoom）

- **操作**：**未拿起任何图片**时，在堆叠区域内**滚动滚轮**（类似 Photoshop 中 Alt/Option + 滚轮）。
- **效果**：
  - **向上滚**：整个内容**放大**（移近），图片视觉上变大，最大 **250%**；
  - **向下滚**：整个内容**缩小**（移远），图片视觉上变小，最小 **50%**；
  - 缩放以**当前指针位置**为中心；
  - 不改变窗口大小，只改变内容显示比例。
- **说明**：与「拿起时滚轮」区分——未拿起时滚轮调节的是**视图**（所有内容一起变大变小），拿起时滚轮调节的是**单张卡片**的 `display_scale`。点击**一览**会将视图缩放与平移一并重置为默认（100%，居中）。

### 5. 长按拿起（Pick up）

- **操作**：在某一卡片上**长按左键**约 **0.5 秒**（桌面端：按下不松手即可，避免与单击/拖拽冲突）。
- **效果**：
  - 该卡片进入「拿起」状态；
  - 卡片会轻微上浮、放大（约 1.12 倍）并带阴影，有短时动画；
  - 之后卡片会**跟随指针**移动（带平滑跟手，有轻微物理感）。
- **说明**：拿起期间该卡片不参与悬停检测，且始终绘制在最上层。

### 6. 拿起时移动（Move while holding）

- **操作**：在「拿起」状态下**移动鼠标**。
- **效果**：卡片中心跟随指针移动；位置通过「抓取偏移」计算，松手时会将卡片放在当前指针位置对应的堆叠位置。若拿起后**将鼠标拖出窗口边缘**，且**设置中已开启「贴图拖拽出窗口」**（默认开启），会转为**系统文件拖放**，可将该图拖到 Windows 文件夹、其它软件输入框等；若关闭该选项，则拖出窗口时仅取消拿起状态，不发起系统拖放。
- **说明**：使用平滑插值（约 0.35 系数）使跟手更自然；指针离开窗口后由系统接管拖放，松手不会在堆叠内放下。

### 7. 拿起时滚轮缩放（Scale while holding）

- **操作**：在「拿起」状态下**滚动滚轮**。
- **效果**：
  - **向上滚**：放大该卡片；
  - **向下滚**：缩小该卡片；
  - 缩放范围：**30%～500%**（相对布局基准尺寸）；
  - 松手后，该缩放会**保留**到该卡片上（`display_scale`），之后在堆叠中也会按此比例显示。
- **说明**：灵敏度由 `WHEEL_SCALE_SENSITIVITY` 控制，避免过快或过慢。

### 8. 松手放下（Put down）

- **操作**：在「拿起」状态下**松开左键**。
- **效果**：
  - 卡片在**当前指针位置**放下；
  - 该卡片会**置顶**（移到堆叠最前）；
  - **视觉尺寸不变**：置顶会改变布局基准尺寸，放下时已按「置顶前后」基准换算 `display_scale`，故拿起时看到的大小与放下后一致；
  - 若在拿起时用滚轮改过缩放，该**缩放会保留**（换算后仍在该卡上）；
  - **旋转落定动画**：**仅在一览状态下**，放下后卡片从当前角度平滑旋转到置顶位置的目标角度（走最短路径），速度较快，约 0.2～0.3 秒内收敛；**阵列状态下**无旋转，放下后图片保持正立，且不会引起其他图片的连带旋转；
  - 拿起状态与临时缩放状态被清除。
- **说明**：放下位置由「抓取偏移」与当前指针计算，保证所见即所得。**随机旋转仅在一览状态下存在**；阵列状态下抓取、放下或拖入的图片均无旋转，且不会带动其他图片旋转。

### 9. 框选多选（Marquee selection）（0.3.0 Phase 2）

- **操作**：在**空白处**（未点到卡片）**按住左键并拖动**，拖出矩形选框。
- **效果**：
  - 松手后，根据选框与每张卡片在屏幕上的 AABB 关系决定选中哪些卡片：**沾到即选中**（交叉选择）；若设置中开启「**AutoDesk 式选取（框选）」**则**从左向右拖**为**仅完全落入选框的图片**被选中（窗口选择），**从右向左拖**为沾到即选中（交叉选择）。
  - 选中的卡片会显示**蓝色描边高亮**；进行中的选框为半透明蓝底+蓝边。
  - **单击某张卡片**（按下并松手未长按拿起）：仅选中该张卡片。
  - **单击空白**或框选未覆盖任何卡片：取消选择。
- **说明**：画板模式下按住**空格 + 左键**为平移，不会触发框选；框选与长按拿起互斥（在空白处按下即开始框选，不会因拖过卡片而变成拿起）。切换目录或模式时选择会清空。成组（Ctrl+G）等组操作依赖此选中集，见 `docs/PRODUCT_ROADMAP_0.3.md` Phase 2。

### 画板模式视口（仅画板模式，与默认/灵感完全解耦）

画板模式使用**独立视口状态**（`board_view_scale`、`board_view_offset`），复刻 Photoshop 的缩放与平移逻辑；默认模式与灵感模式不受影响，仍使用原有 `view_scale` / `view_offset`。**默认/灵感**下拖边改变视窗大小时，会对 `view_offset` 做与画板一致的**中心位移补偿**，原先在内容区中心的世界点仍留在原屏幕位置，整幅内容不因 resize 移位。

**三个核心坐标系**

- **世界坐标 (World Space)**：图片与对象的原始位置（画板中为参考空间下的 `board_saved_world_pos` 等），不随视口变化。
- **视口状态 (View State)**：`scale`（缩放倍率，1.0 = 100%）、`offsetX` / `offsetY`（平移偏移，世界单位）；仅通过视口变换影响显示，不修改物体尺寸。
- **屏幕坐标 (Screen Space)**：用户在窗口内看到的像素位置。变换公式：`screen = 内容区中心 + scale × (world - offset)`。

**缩放（Zoom）**

- **操作**：未拿起图片时在画板区域**滚动滚轮**。
- **原则**：以**鼠标为中心缩放**，缩放前后鼠标指针下的世界坐标点保持在同一屏幕像素上，不跳动。数学上：缩放从 `s1` 变为 `s2` 时，`offset` 更新为 `offset += (鼠标屏幕 - 内容区中心) × (1/s1 - 1/s2)`。
- **说明**：不修改图片的 width/height，所有缩放通过视口变换在渲染层完成（与默认/灵感一致）。

**平移（Pan）**

- **操作**：**中键拖动**，或 **空格 + 左键拖动**（复刻 PS 空格拖画布）。
- **逻辑**：记录起点后，在移动中将**位移差（Delta）**累加到 `offsetX` / `offsetY`；平移不改变缩放倍率，仅改变可见区域。方向受设置中「反转平移方向」影响（中键与空格+左键一致）。
- **说明**：画板模式下按住**空格**时左键拖动为平移，**不会**触发长按拿起。

**窗口调整（Window Resize）**

- 当内容区（CentralPanel）大小改变时：将**窗口中心点的位移**补偿到 `offset` 中（`offset -= 中心位移 / scale`），确保原先位于画布中心的世界点仍停留在新的中心位置，不拉伸内容、不改变 `scale`。

**左侧边栏（模式切换）**

- **默认** / **灵感** / **画板**：三个带圆角的小方块按钮，位于**左侧边栏垂直居中**（避免被窗口导航栏挡住），点击切换模式。**默认模式**展示主文件夹（如 `Pictures/Ref`）中的图片。**灵感模式**（Windows）：打开时默认展示 **Windows 最近使用的文件**中的图片（最多 30 张），并合并 **Ref/Screenshots** 截图文件夹中的图片（screenshot-1.png、screenshot-2.png… 按编号排序）；在该模式下拖入或粘贴保存的图片会存入 `Ref/Inspiration`，新保存的图也会出现在列表中（总数上限 30）。**画板模式**：画布与「当前目录」绑定，卡片位置、缩放、顺序持久化到该目录内的 **`.deckref_layout.json`**（sidecar）；切换目录或重启后若存在该文件则恢复布局，无则使用默认散落。画板模式下同样显示地址栏与最近到访，可切换目录；每次成功写入布局的目录会登记到配置目录下的 `layout_dirs.txt`，供卸载时可选清理。**运行时剪贴板截图**：仅当**按下 Shift 后的约 5 秒内**才会把剪贴板中新出现的图片当作截图自动保存到 **Ref/Screenshots**（screenshot-编号.png）；若当前为灵感模式，新截图会立即出现在堆叠中（带落下动画）。未按 Shift 或超时后不保存，避免误存 QQ/浏览器等复制的图片。应用仍会定期读取剪贴板以更新内部状态，便于进入监听窗口时不误存旧内容。非 Windows 下灵感模式仍展示 `Ref/Inspiration` 目录及 Ref/Screenshots 中的截图。切换模式时会**保留另一模式的卡片与纹理缓存**，再次切回时直接恢复、无需重扫磁盘，减少卡顿。

**顶部（主工具栏）**

- **地址栏（默认模式与画板模式）**：按 **Windows 11 资源管理器** 的地址栏操作。顺序是 **◀ 后退**、**▶ 前进**、**↑ 向上一级**，然后是面包屑。每一级是资源管理器里的**显示名**（例如盘符为「本地磁盘 (C:)」，图片库为「图片」），名称右边各有一个 **›**。**点击名称**打开该文件夹；**点击它右边的 ›**，菜单出现在这个箭头正下方，列出**这一层里的子文件夹**（不含文件，不含隐藏/系统目录，按资源管理器的名称顺序）。根是 **「此电脑」**：点名称不会乱跳到某个盘；点它右边的 ›，列表先是桌面、文档、下载、音乐、图片、视频，再是各磁盘（带卷标）。没有子文件夹时箭头仍在，菜单为空。**地址栏放不下时**：左侧收成一个 **›**，点它在箭头下方列出被收起的上级（从「此电脑」往下）；窗口变宽后自动展开。**点击地址栏右侧空白**或按 **Ctrl+L**（Mac：**Cmd+L**）进入编辑：整栏变成路径文本并**全选**，可输入或粘贴。**Enter** 或点到栏外时，若路径有改动且是有效目录则跳转；**Esc** 放弃修改。盘符会规范成盘根（`F:\`），不会掉进该盘的当前工作目录。**最近访问**在地址栏左侧，列出最近 **5** 个文件夹（不含当前目录），点击即切换，并缓存卡片。列表在关闭软件时写入 `recent_folders.txt`。**启动时**默认模式恢复上次文件夹。
- **按名称**：按文件名对卡片列表排序。
- **按大小**：按文件大小排序。
- **按修改时间**：按修改时间排序（新的在前）。
- **清空**：清空当前所有卡片与纹理缓存。
- **设置（⚙）**：右上角齿轮，打开设置窗口；可勾选「反转平移方向（中键拖动）」以切换平移方向；可勾选「贴图拖拽出窗口」以开启/关闭拿起后拖出窗口时的系统文件拖放（默认开启）；可勾选「**预览专业格式图片**」以开启 TGA、ICO、DDS、AVIF、EXR、HDR、PNM、QOI、PSD 等格式的预览（更改后会重新加载当前目录）。**设置会保存到本地，关闭再打开软件后自动恢复。**

**底部左侧（桌面端：与窗口标题栏/控制区分离，减少误触）**

- **一览**：一键打散所有图片，使其在**当前窗口内随机、均匀分布**，并带平滑位移动画；用于**快速浏览当前文件夹里有哪些图片**。同时将**视图缩放与平移重置为默认**（100% 缩放、居中）。**随机旋转仅在一览状态下存在**（散落效果）。可多次点击，每次重新随机排布。
- **阵列**：**单次触发**，与「一览」类似。点击后把图片按**网格、原比例**（contain）排列到合适大小，带位移动画；排列后仍可**自由拖动、拿起、缩放视图**等。**阵列状态下图片无随机旋转**，抓取、放下或拖入的图片均保持正立，且不会引起其他图片旋转。再次点击会再次执行阵列排列。便于快速观看所有图片全貌。

**底部右侧**

- **版本号**：软件**右下角**始终显示当前版本号（如 v0.3.3），以**半透明灰色**显示，不干扰主操作。
- **按住图片时显示文件名**：当用户**左键点住某张图片**（长按尚未拿起、或已拿起未松手）时，在**右下角**显示该图片的**完整文件名**（含扩展名），同样为半透明灰色；长文件名会截断显示，避免挤占版本号。

---

- **操作**：从**浏览器、资源管理器或任意软件**中**长按并拖动一张图片**，拖入 DeckRef 窗口后松手（窗口已开启接受拖放，不会显示禁止标志）。
- **效果**：
  - 若拖入的是**监听目录内已存在的图片**（同一文件）：**不复制**，仅将该图对应的卡片**置顶**；
  - 若拖入的是**刚从本窗口拖出、又原样拖回的同一张图**（未保存到别处）：**不复制**，仅将该图对应的卡片**置顶**，避免循环保存；
  - 若拖入的是**监听目录外的本地文件**：将文件**复制**到监听目录，保留原格式与分辨率，文件名格式为「原主名_时间戳.扩展名」避免覆盖；
  - 若拖入的是**纯图片数据**（如浏览器内图片，无本地路径）：在内存中解码后**保存为 PNG** 到监听目录，文件名为「capture_时间戳.png」；
  - 保存后由**文件监听**自动将新图加入堆叠；**新加入的图片**会播放短暂的**落下动画**（从上方落定、缩放收敛），仅动效优化，不影响操作。
- **说明**：支持常见格式（PNG、JPEG、GIF、BMP、WebP、TIFF 等）；本地文件采用复制不重新编码，保证高效与画质；纯字节数据统一保存为 PNG 以保证质量。**若从 Chrome 等浏览器拖入无效**（受系统/浏览器拖放协议限制），可使用下方「剪贴板粘贴」方式。

## 四、剪贴板粘贴（Chrome 等拖入无效时的备用方案）

- **操作**：在浏览器或任意软件中**复制图片**（如 Chrome：右键图片 → 复制图片），然后焦点在 DeckRef 窗口时按 **Ctrl+V**（Mac：**Cmd+V**）。
- **效果**：将剪贴板中的图片以 PNG 保存到监听目录，并由文件监听加入堆叠，带落下动画。
- **说明**：不涉及额外权限，仅读取系统剪贴板；无图片时按键无效果。

## 五、数据与布局

- **监听路径**：由**当前模式**决定。**默认模式**下监听路径是 Windows 11 式面包屑：点名称进入该级，点右侧 › 列出该级子文件夹；根「此电脑」的 › 列出桌面/文档/下载/音乐/图片/视频和各磁盘；**启动时恢复上次关闭时的文件夹**（保存于配置目录 `last_path.txt`）。**灵感模式**（Windows）：展示 **Windows 最近使用的文件**中的图片与 **Ref/Screenshots** 截图文件夹中的图片（screenshot-编号.png），总数最多 30 张；**仅当按下 Shift 后的约 5 秒内**剪贴板新图才会写入 Ref/Screenshots 并在灵感模式下即时显示。非 Windows 下灵感模式监听 `Ref/Inspiration` 并合并 Ref/Screenshots。**画板模式**：监听路径同由地址栏/最近到访选择，**启动或切回画板时恢复上次使用的目录**（配置目录 `last_board_path.txt`）；该目录下的 **`.deckref_layout.json`** 保存卡片位置（offset）、旋转（rotation）、缩放（scale）与顺序，进入或切换至该目录时若存在则加载并应用，否则使用默认散落；退出、切换目录或约每 5 秒防抖写入一次布局，成功写入的目录会追加到配置目录 `layout_dirs.txt` 供卸载时可选清理。**易用性：默认与画板的文件夹地址同步**——在任一模式中切换目录或切换模式时，会同时更新 `last_path.txt` 与 `last_board_path.txt`，因此切到默认或画板时都会打开**同一文件夹**；两模式仍各自独立（存储文件、布局逻辑分离），仅路径做双写同步。堆叠顺序、单卡偏移与旋转等与默认模式一致。
- **堆叠顺序**：列表顺序 = 从后到前；索引越大越靠前、显示越大。
- **单卡偏移与旋转**：每张卡有 `random_offset`、`random_rotation`（由路径哈希生成）。**随机旋转仅在一览状态下生效**；阵列状态下所有图片显示无旋转，抓取、放下或拖入均不产生旋转也不引起其他图片连带旋转。一览下拿起后松手会更新该卡的 `random_offset` 与 `display_scale`；放下瞬间会设 `anim_rotation_offset`，每帧向 0 收敛，实现旋转落定动画。**一览**会重新计算每张卡的 `random_offset` 并在网格内随机打乱，带 `anim_position_delta` 平滑动画。
- **空文件夹提示**：当**当前打开的文件夹中没有任何可预览的图片**时，在**视窗正中央**显示一行提示：「当前文件夹中没有可以预览的图片」；文字为**加粗感**（略大字号、深灰），外围有**圆角矩形框**（浅色描边与半透明底），加强提醒，避免用户误以为软件无响应或路径错误。

## 七、开发与维护说明

- 交互相关常量（长按时长、缩放范围、跟手系数等）集中在 `src/image_card.rs` 与 `src/app/mod.rs` 中。
- **设置持久化**：反转平移方向、贴图拖拽出窗口、预览专业格式图片等选项保存在配置目录（与窗口状态相同：Windows `%APPDATA%\DeckRef\settings.txt`，Unix `~/.config/deckref/settings.txt`），关闭再打开软件后自动加载。
- 新增或修改交互时，请同步更新本文档，并保持「操作 → 条件 → 效果」描述一致。
- 本文档作为交互设计的单一来源，开发时优先查阅，可减少遗漏与冲突。
