# DeckRef 交互方式说明

本文档描述 DeckRef 当前支持的所有交互方式，便于开发与使用时的统一理解。**开发时请优先查阅并维护本文档**，再修改交互逻辑。

**适用平台**：Mac / Windows 桌面端（鼠标、触控板、滚轮）。

---

## 零、窗口与启动

- **窗口尺寸与位置记忆**：关闭窗口时会记录当前窗口的**位置**（外框左上角）和**内尺寸**；下次启动时按相同位置与尺寸打开，无需每次重新调整。
  - **显示器**：通过保存位置实现「记住哪台显示器」——系统会根据该坐标把窗口放到包含该点的显示器上；多屏时窗口会回到上次所在的那块屏。
  - 若从未保存过或文件无效，则使用默认尺寸（360×240），位置由系统决定。
  - 尺寸约束在约 200～3840（宽）、150～2160（高）；位置约束在合理范围内，避免异常恢复。
- **最小尺寸限制**：窗口不允许被拖拽到比 **200×150**（内容区）更小，保证工具栏与操作区域可用。

## 一、鼠标 / 触控板

以下交互以鼠标为主，触控板通常映射为相同行为（左键=主键，双指滚动=滚轮）。

### 1. 悬停（Hover）

- **操作**：将指针悬停在某张卡片上。
- **效果**：该卡片会轻微放大（约 1.08 倍），带有平滑动画；不改变顺序与位置。
- **说明**：命中检测按从最前到最后的顺序，仅最上层卡片响应悬停。

### 2. 视角平移（Pan）

- **操作**：按住**鼠标中键**并拖动。
- **效果**：整个堆叠区域随指针移动，实现画布平移。默认：拖动方向与内容移动方向一致（拖右则内容向右）。
- **说明**：若感觉方向相反，可在**设置**（右上角齿轮）中勾选「反转平移方向」。

### 3. 缩放视图（View zoom）

- **操作**：**未拿起任何图片**时，在堆叠区域内**滚动滚轮**（类似 Photoshop 中 Alt/Option + 滚轮）。
- **效果**：
  - **向上滚**：整个内容**放大**（移近），图片视觉上变大，最大 **250%**；
  - **向下滚**：整个内容**缩小**（移远），图片视觉上变小，最小 **50%**；
  - 缩放以**当前指针位置**为中心；
  - 不改变窗口大小，只改变内容显示比例。
- **说明**：与「拿起时滚轮」区分——未拿起时滚轮调节的是**视图**（所有内容一起变大变小），拿起时滚轮调节的是**单张卡片**的 `display_scale`。点击**一览**会将视图缩放与平移一并重置为默认（100%，居中）。

### 4. 长按拿起（Pick up）

- **操作**：在某一卡片上**长按左键**约 **0.5 秒**（桌面端：按下不松手即可，避免与单击/拖拽冲突）。
- **效果**：
  - 该卡片进入「拿起」状态；
  - 卡片会轻微上浮、放大（约 1.12 倍）并带阴影，有短时动画；
  - 之后卡片会**跟随指针**移动（带平滑跟手，有轻微物理感）。
- **说明**：拿起期间该卡片不参与悬停检测，且始终绘制在最上层。

### 5. 拿起时移动（Move while holding）

- **操作**：在「拿起」状态下**移动鼠标**。
- **效果**：卡片中心跟随指针移动；位置通过「抓取偏移」计算，松手时会将卡片放在当前指针位置对应的堆叠位置。若拿起后**将鼠标拖出窗口边缘**，且**设置中已开启「贴图拖拽出窗口」**（默认开启），会转为**系统文件拖放**，可将该图拖到 Windows 文件夹、其它软件输入框等；若关闭该选项，则拖出窗口时仅取消拿起状态，不发起系统拖放。
- **说明**：使用平滑插值（约 0.35 系数）使跟手更自然；指针离开窗口后由系统接管拖放，松手不会在堆叠内放下。

### 6. 拿起时滚轮缩放（Scale while holding）

- **操作**：在「拿起」状态下**滚动滚轮**。
- **效果**：
  - **向上滚**：放大该卡片；
  - **向下滚**：缩小该卡片；
  - 缩放范围：**30%～500%**（相对布局基准尺寸）；
  - 松手后，该缩放会**保留**到该卡片上（`display_scale`），之后在堆叠中也会按此比例显示。
- **说明**：灵敏度由 `WHEEL_SCALE_SENSITIVITY` 控制，避免过快或过慢。

### 7. 松手放下（Put down）

- **操作**：在「拿起」状态下**松开左键**。
- **效果**：
  - 卡片在**当前指针位置**放下；
  - 该卡片会**置顶**（移到堆叠最前）；
  - 若在拿起时用滚轮改过缩放，该**缩放会保留**；
  - **旋转落定动画**：放下后卡片从当前角度平滑旋转到置顶位置的目标角度（走最短路径），速度较快，约 0.2～0.3 秒内收敛，交互更自然；
  - 拿起状态与临时缩放状态被清除。
- **说明**：放下位置由「抓取偏移」与当前指针计算，保证所见即所得。

## 二、顶部与底部工具栏

**左侧边栏（模式切换）**

- **默认** / **灵感**：两个带圆角的小方块按钮，位于**左侧边栏垂直居中**（避免被窗口导航栏挡住），点击切换模式。**默认模式**展示主文件夹（如 `Pictures/Ref`）中的图片。**灵感模式**（Windows）：打开时默认展示 **Windows 最近使用的文件**中的图片（最多 30 张），无需指定文件夹即可快速查看最近看过的图；在该模式下拖入或粘贴保存的图片会存入 `Ref/Inspiration`，新保存的图也会出现在列表中（总数上限 30）。非 Windows 下灵感模式仍展示 `Ref/Inspiration` 目录。切换模式时会**保留另一模式的卡片与纹理缓存**，再次切回时直接恢复、无需重扫磁盘，减少卡顿。

**顶部（主工具栏）**

- **地址栏（仅默认模式）**：监听路径以 **面包屑导航** 显示，风格类似 Windows 资源管理器。**根目录**为「此台电脑」（Windows）：点击可展开**盘符列表**（C:、D: 等），选择后切换到该盘。其余段落为路径层级；**点击任意段落**可切换到该级目录；**当前目录**以粗体显示；当前目录右侧若有 **▾**，可展开**子目录列表**（最多 80 个）快速切换。地址栏左侧有 **◀ 后退** 与 **▶ 前进** 按钮，可沿本次会话的浏览历史前后跳转。路径过长时可横向滚动。**点击末端「▤ 输入或粘贴路径」**可进入编辑模式：显示当前路径的单行输入框，可**输入或粘贴**任意路径，**Enter** 确认并跳转（若为有效目录），**Esc** 取消。**导航栏最右侧**有 **▾** 按钮，点击打开**最近到访**下拉菜单，显示最近访问的 **5 个文件夹**（当前目录不显示）；点击任一项可快速切换，且这 5 个文件夹的卡片会做**缓存**，再次点选时无需重新加载。最近到访列表会**在关闭软件时写入磁盘**（配置目录 `recent_folders.txt`），下次启动后仍可看到并快速切换。**启动时**默认模式会恢复**上次关闭时**所在的文件夹（与窗口位置、尺寸一并持久化）。
- **按名称**：按文件名对卡片列表排序。
- **按大小**：按文件大小排序。
- **按修改时间**：按修改时间排序（新的在前）。
- **清空**：清空当前所有卡片与纹理缓存。
- **设置（⚙）**：右上角齿轮，打开设置窗口；可勾选「反转平移方向（中键拖动）」以切换平移方向；可勾选「贴图拖拽出窗口」以开启/关闭拿起后拖出窗口时的系统文件拖放（默认开启）。**设置会保存到本地，关闭再打开软件后自动恢复。**

**底部左侧（桌面端：与窗口标题栏/控制区分离，减少误触）**

- **一览**：一键打散所有图片，使其在**当前窗口内随机、均匀分布**，并带平滑位移动画；用于**快速浏览当前文件夹里有哪些图片**。同时将**视图缩放与平移重置为默认**（100% 缩放、居中）。可多次点击，每次重新随机排布。
- **阵列**：**单次触发**，与「一览」类似。点击后把图片按**网格、原比例**（contain）排列到合适大小，带位移动画；排列后仍可**自由拖动、拿起、缩放视图**等。再次点击会再次执行阵列排列。便于快速观看所有图片全貌。

## 三、快捷抓图（拖入保存）

- **操作**：从**浏览器、资源管理器或任意软件**中**长按并拖动一张图片**，拖入 DeckRef 窗口后松手（窗口已开启接受拖放，不会显示禁止标志）。
- **效果**：
  - 若拖入的是**监听目录内已存在的图片**（同一文件）：**不复制**，仅将该图对应的卡片**置顶**；
  - 若拖入的是**刚从本窗口拖出、又原样拖回的同一张图**（未保存到别处）：**不复制**，仅将该图对应的卡片**置顶**，避免循环保存；
  - 若拖入的是**监听目录外的本地文件**：将文件**复制**到监听目录，保留原格式与分辨率，文件名格式为「原主名_时间戳.扩展名」避免覆盖；
  - 若拖入的是**纯图片数据**（如浏览器内图片，无本地路径）：在内存中解码后**保存为 PNG** 到监听目录，文件名为「capture_时间戳.png」；
  - 保存后由**文件监听**自动将新图加入堆叠；**新加入的图片**会播放短暂的**落下动画**（从上方落定、缩放收敛），仅动效优化，不影响操作。
- **说明**：支持常见格式（PNG、JPEG、GIF、BMP、WebP、TIFF 等）；本地文件采用复制不重新编码，保证高效与画质；纯字节数据统一保存为 PNG 以保证质量。**若从 Chrome 等浏览器拖入无效**（受系统/浏览器拖放协议限制），可使用下方「剪贴板粘贴」方式。

## 四、剪贴板粘贴（Chrome 等拖入无效时的备用方案）

- **操作**：在浏览器或任意软件中**复制图片**（如 Chrome：右键图片 → 复制图片），然后焦点在 DeckRef 窗口时按 **Ctrl+V**（Mac：**Cmd+V**）。
- **效果**：将剪贴板中的图片以 PNG 保存到监听目录，并由文件监听加入堆叠，带落下动画。
- **说明**：不涉及额外权限，仅读取系统剪贴板；无图片时按键无效果。

## 五、数据与布局

- **监听路径**：由**当前模式**决定。**默认模式**下监听路径显示为可点击的面包屑，根为「此台电脑」可选盘符，可点击任意上级或通过当前目录旁的 ▾ 选择子目录切换；**启动时恢复上次关闭时的文件夹**（保存于配置目录 `last_path.txt`）。**灵感模式**（Windows）：展示 **Windows 最近使用的文件**中的图片（最多 30 张），来源为 `%APPDATA%\Microsoft\Windows\Recent` 内的快捷方式解析出的本地图片路径；拖入或粘贴保存的图片会写入 `Ref/Inspiration` 并加入列表（总数上限 30）。非 Windows 下灵感模式监听 `Ref/Inspiration`。堆叠顺序、单卡偏移与旋转等与默认模式一致。
- **堆叠顺序**：列表顺序 = 从后到前；索引越大越靠前、显示越大。
- **单卡偏移与旋转**：每张卡有 `random_offset`、`random_rotation`（由路径哈希生成），用于散落效果；拿起后松手会更新该卡的 `random_offset` 与 `display_scale`。放下瞬间会设 `anim_rotation_offset`，每帧向 0 收敛，实现旋转落定动画。**一览**会重新计算每张卡的 `random_offset` 并在网格内随机打乱，带 `anim_position_delta` 平滑动画。

## 六、交互汇总表

| 操作               | 条件           | 效果                     |
|--------------------|----------------|--------------------------|
| 关闭窗口           | 用户点击关闭   | 保存当前窗口位置与尺寸；下次启动按相同位置与尺寸打开（含所在显示器）；窗口不可小于 200×150 |
| 悬停               | 指针在卡片上   | 卡片轻微放大             |
| 中键拖动           | 任意           | 视角平移                 |
| 滚轮（未拿起）     | 未拿起任何卡片 | 视图缩放 50%～250%，以指针为中心 |
| 长按左键 ≥0.5s     | 指针在卡片上   | 拿起该卡片               |
| 拿起 + 移动        | 已拿起         | 跟手移动；若开启「贴图拖拽出窗口」则指针离开窗口边缘可拖出到文件夹/其它软件 |
| 拿起 + 滚轮        | 已拿起         | 单卡缩放 30%～500%，松手保留 |
| 松手               | 已拿起         | 放下、置顶、保留缩放、旋转落定动画 |
| 顶部按钮           | 点击           | 排序 / 清空              |
| 顶部「设置」⚙     | 点击           | 打开设置，可反转平移方向、开关贴图拖拽出窗口；设置持久化，重启后恢复 |
| 左侧「默认」「灵感」 | 点击           | 切换模式；默认=主文件夹；灵感=Windows 最近图片（最多 30）或 Ref/Inspiration，保存入 Inspiration |
| 底部「一览」       | 点击           | 打散并均匀分布、视图重置为默认 |
| 底部「阵列」       | 点击           | 单次触发：按网格、原比例排列，之后仍可自由拖动 |
| 从外部拖入图片到窗口 | 任意           | 新图：保存并落下动画；已在监听目录的图或刚拖出又拖回的图：仅置顶不复制 |
| Ctrl+V / Cmd+V       | 焦点在窗口     | 剪贴板图片保存到监听目录并加入堆叠（Chrome 拖入无效时的备用） |

## 七、开发与维护说明

- 交互相关常量（长按时长、缩放范围、跟手系数等）集中在 `src/image_card.rs` 与 `src/app.rs` 中。
- **设置持久化**：反转平移方向、贴图拖拽出窗口等选项保存在配置目录（与窗口状态相同：Windows `%APPDATA%\DeckRef\settings.txt`，Unix `~/.config/deckref/settings.txt`），关闭再打开软件后自动加载。
- 新增或修改交互时，请同步更新本文档，并保持「操作 → 条件 → 效果」描述一致。
- 本文档作为交互设计的单一来源，开发时优先查阅，可减少遗漏与冲突。
