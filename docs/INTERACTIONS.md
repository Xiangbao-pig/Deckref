# DeckRef 交互方式说明

本文档描述 DeckRef 当前支持的所有交互方式，便于开发与使用时的统一理解。**开发时请优先查阅并维护本文档**，再修改交互逻辑。

**适用平台**：Mac / Windows 桌面端（鼠标、触控板、滚轮）。

---

## 一、鼠标 / 触控板

以下交互以鼠标为主，触控板通常映射为相同行为（左键=主键，双指滚动=滚轮）。

### 1. 悬停（Hover）

- **操作**：将指针悬停在某张卡片上。
- **效果**：该卡片会轻微放大（约 1.08 倍），带有平滑动画；不改变顺序与位置。
- **说明**：命中检测按从最前到最后的顺序，仅最上层卡片响应悬停。

### 2. 视角平移（Pan）

- **操作**：按住**鼠标中键**并拖动。
- **效果**：整个堆叠区域随指针移动，实现画布平移。默认：拖动方向与内容移动方向一致（拖右则内容向右）。
- **说明**：若感觉方向相反，可在**设置**（右上角齿轮）中勾选「反转平移方向」。

### 3. 缩放视图（View zoom）

- **操作**：**未拿起任何图片**时，在堆叠区域内**滚动滚轮**（类似 Photoshop 中 Alt/Option + 滚轮）。
- **效果**：
  - **向上滚**：整个内容**放大**（移近），图片视觉上变大，最大 **250%**；
  - **向下滚**：整个内容**缩小**（移远），图片视觉上变小，最小 **50%**；
  - 缩放以**当前指针位置**为中心；
  - 不改变窗口大小，只改变内容显示比例。
- **说明**：与「拿起时滚轮」区分——未拿起时滚轮调节的是**视图**（所有内容一起变大变小），拿起时滚轮调节的是**单张卡片**的 `display_scale`。点击**一览**会将视图缩放与平移一并重置为默认（100%，居中）。

### 4. 长按拿起（Pick up）

- **操作**：在某一卡片上**长按左键**约 **0.5 秒**（桌面端：按下不松手即可，避免与单击/拖拽冲突）。
- **效果**：
  - 该卡片进入「拿起」状态；
  - 卡片会轻微上浮、放大（约 1.12 倍）并带阴影，有短时动画；
  - 之后卡片会**跟随指针**移动（带平滑跟手，有轻微物理感）。
- **说明**：拿起期间该卡片不参与悬停检测，且始终绘制在最上层。

### 5. 拿起时移动（Move while holding）

- **操作**：在「拿起」状态下**移动鼠标**。
- **效果**：卡片中心跟随指针移动；位置通过「抓取偏移」计算，松手时会将卡片放在当前指针位置对应的堆叠位置。若拿起后**将鼠标拖出窗口边缘**，会转为**系统文件拖放**，可将该图拖到 Windows 文件夹、其它软件输入框等。
- **说明**：使用平滑插值（约 0.35 系数）使跟手更自然；指针离开窗口后由系统接管拖放，松手不会在堆叠内放下。

### 6. 拿起时滚轮缩放（Scale while holding）

- **操作**：在「拿起」状态下**滚动滚轮**。
- **效果**：
  - **向上滚**：放大该卡片；
  - **向下滚**：缩小该卡片；
  - 缩放范围：**30%～500%**（相对布局基准尺寸）；
  - 松手后，该缩放会**保留**到该卡片上（`display_scale`），之后在堆叠中也会按此比例显示。
- **说明**：灵敏度由 `WHEEL_SCALE_SENSITIVITY` 控制，避免过快或过慢。

### 7. 松手放下（Put down）

- **操作**：在「拿起」状态下**松开左键**。
- **效果**：
  - 卡片在**当前指针位置**放下；
  - 该卡片会**置顶**（移到堆叠最前）；
  - 若在拿起时用滚轮改过缩放，该**缩放会保留**；
  - **旋转落定动画**：放下后卡片从当前角度平滑旋转到置顶位置的目标角度（走最短路径），速度较快，约 0.2～0.3 秒内收敛，交互更自然；
  - 拿起状态与临时缩放状态被清除。
- **说明**：放下位置由「抓取偏移」与当前指针计算，保证所见即所得。

## 二、顶部与底部工具栏

**顶部（主工具栏）**

- **按名称**：按文件名对卡片列表排序。
- **按大小**：按文件大小排序。
- **按修改时间**：按修改时间排序（新的在前）。
- **清空**：清空当前所有卡片与纹理缓存。
- **设置（⚙）**：右上角齿轮，打开设置窗口；可勾选「反转平移方向（中键拖动）」以切换平移方向。

**底部左侧（桌面端：与窗口标题栏/控制区分离，减少误触）**

- **一览**：一键打散所有图片，使其在**当前窗口内随机、均匀分布**，并带平滑位移动画；用于**快速浏览当前文件夹里有哪些图片**。同时将**视图缩放与平移重置为默认**（100% 缩放、居中）。可多次点击，每次重新随机排布。

## 三、快捷抓图（拖入保存）

- **操作**：从**浏览器、资源管理器或任意软件**中**长按并拖动一张图片**，拖入 DeckRef 窗口后松手（窗口已开启接受拖放，不会显示禁止标志）。
- **效果**：
  - 若拖入的是**监听目录内已存在的图片**（同一文件）：**不复制**，仅将该图对应的卡片**置顶**；
  - 若拖入的是**监听目录外的本地文件**：将文件**复制**到监听目录，保留原格式与分辨率，文件名格式为「原主名_时间戳.扩展名」避免覆盖；
  - 若拖入的是**纯图片数据**（如浏览器内图片，无本地路径）：在内存中解码后**保存为 PNG** 到监听目录，文件名为「capture_时间戳.png」；
  - 保存后由**文件监听**自动将新图加入堆叠；**新加入的图片**会播放短暂的**落下动画**（从上方落定、缩放收敛），仅动效优化，不影响操作。
- **说明**：支持常见格式（PNG、JPEG、GIF、BMP、WebP、TIFF 等）；本地文件采用复制不重新编码，保证高效与画质；纯字节数据统一保存为 PNG 以保证质量。

## 四、数据与布局

- **监听路径**：启动时指定并显示的目录，新放入的图片会自动加入堆叠（有数量上限，约 80 张）。
- **堆叠顺序**：列表顺序 = 从后到前；索引越大越靠前、显示越大。
- **单卡偏移与旋转**：每张卡有 `random_offset`、`random_rotation`（由路径哈希生成），用于散落效果；拿起后松手会更新该卡的 `random_offset` 与 `display_scale`。放下瞬间会设 `anim_rotation_offset`，每帧向 0 收敛，实现旋转落定动画。**一览**会重新计算每张卡的 `random_offset` 并在网格内随机打乱，带 `anim_position_delta` 平滑动画。

## 五、交互汇总表

| 操作               | 条件           | 效果                     |
|--------------------|----------------|--------------------------|
| 悬停               | 指针在卡片上   | 卡片轻微放大             |
| 中键拖动           | 任意           | 视角平移                 |
| 滚轮（未拿起）     | 未拿起任何卡片 | 视图缩放 50%～250%，以指针为中心 |
| 长按左键 ≥0.5s     | 指针在卡片上   | 拿起该卡片               |
| 拿起 + 移动        | 已拿起         | 跟手移动；指针离开窗口边缘可拖出到文件夹/其它软件 |
| 拿起 + 滚轮        | 已拿起         | 单卡缩放 30%～500%，松手保留 |
| 松手               | 已拿起         | 放下、置顶、保留缩放、旋转落定动画 |
| 顶部按钮           | 点击           | 排序 / 清空              |
| 顶部「设置」⚙     | 点击           | 打开设置，可反转平移方向 |
| 底部「一览」       | 点击           | 打散并均匀分布、视图重置为默认 |
| 从外部拖入图片到窗口 | 任意           | 新图：保存并落下动画；已在监听目录的图：仅置顶不复制 |

## 六、开发与维护说明

- 交互相关常量（长按时长、缩放范围、跟手系数等）集中在 `src/image_card.rs` 与 `src/app.rs` 中。
- 新增或修改交互时，请同步更新本文档，并保持「操作 → 条件 → 效果」描述一致。
- 本文档作为交互设计的单一来源，开发时优先查阅，可减少遗漏与冲突。
