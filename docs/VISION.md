# DeckRef 项目愿景（参考）

> 本文档为**愿景与方向参考**，不参与具体开发约束。实现与交互以 `INTERACTIONS.md`、架构文档和代码为准。

---

DeckRef 的定位是：

**用 Rust 实现的、符合艺术家直觉的图片管理与预览工具——优先直觉体验与效率。**

- **符合艺术家直觉**：交互贴近「摆参考图、看图、比对」的直觉，少学习成本、少打断思路。
- **图片管理 + 预览**：既能管理/浏览目录下的图片，又能舒适地预览、堆叠、缩放与拖拽使用。
- **主动直觉与效率**：操作路径短、反馈清晰；在保证直觉的前提下，不牺牲性能与操作效率。

开发时以现有规范与文档为准；在做**产品与交互方向**的取舍时，可把本文档当作参考，不必逐条落实为硬性需求。
