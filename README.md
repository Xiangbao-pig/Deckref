# DeckRef

**当前版本：0.3.2** · 一个「选个文件夹就能用」的本地图片参考板。

用 Rust + eframe/egui 写的 **AI Native** 桌面小工具：指定一个文件夹，里面的图片自动堆叠成画布；拖入、粘贴即存；画板模式下摆好的位置和缩放跟着文件夹走，不用另建项目文件。适合攒参考图、对镜头、随手整理截图。

---

## 我们觉得还不错的几点

- **直觉操作优先**  
  长按拿起、松手放下、滚轮缩放、中键/空格平移……尽量少记快捷键，多靠「拖一拖、滚一滚」完成日常操作。画板模式的视窗逻辑也按「窗口是取景框、画布固定」来设计，拉大窗口就是多看一块画布，不重新排版。

- **本地、不联网**  
  图片和布局都在你自己机器上。监听目录你定，配置和窗口状态放在系统配置目录（如 Windows `%APPDATA%\DeckRef`），没有账号、没有同步、没有上传。

- **多种视窗模式**  
  **默认**：自选文件夹，地址栏 + 最近到访 + 后退前进。**灵感**：最近使用的文件 + 截图目录，适合快速抓图。**画板**：画布和当前文件夹绑定，位置/缩放/顺序持久化，换目录或重启后自动恢复。

- **文件夹即画布，不用「另存为」**  
  选好监听路径就开始用；画板模式下布局写在**该目录下的一个 sidecar 文件**里（`.deckref_layout.json`），和图片在一起。复制或移动整个文件夹，布局也跟着走，不需要单独导出/导入项目。

## 现在能做什么

- 监听一个文件夹，新放进来的图片自动进堆叠；拖入窗口即保存到该目录（支持从浏览器拖入、Ctrl+V 粘贴）。
- 长按拿起 → 跟手移动、滚轮改单张缩放 → 松手放下并置顶；拿起后拖出窗口可丢到系统文件夹或其它软件。
- 中键或空格+左键平移画布；滚轮缩放视图（以指针为中心）；画板下视窗 resize 时保持「画布中心不动」。
- 框选多选（空白处拖出选框），可选「AutoDesk 式」左/右拖不同选法；单击卡片/空白选中/取消选择。
- 一览打散、阵列紧密排列；地址栏面包屑、最近到访、路径编辑与恢复上次文件夹。
- 画板模式：布局按目录持久化，切换目录或重启后恢复；窗口当取景框，画布尺寸与元素位置不随窗口缩放而变。
- 设置持久化（反转平移、拖出窗口、预览专业格式等）；窗口尺寸与位置记忆，多屏时回到上次那块屏。

更细的交互见 [docs/INTERACTIONS.md](docs/INTERACTIONS.md)。

## 以后可能会有的

- **成组 / 取消分组**：框选多张后成组，一起移动（乃至一起缩放）；右键与快捷键加入组、移出组、取消分组。
- **TAB 文件夹树**：按 TAB 呼出侧边文件夹树，快速切目录。
- **刷新 + 适应全部**：顶部「刷新」重载当前目录并让视口自动包住所有卡片；右键空白菜单（粘贴、刷新、新建便签等）。
- **右键图片菜单**：打开方式、置顶、复制路径/图片、加入组/移出组、移到最前/最后等。
- **便签**：画布上放纯文本便签，位置随布局保存（计划在 0.4.x）。
- **导出 / 始终置顶**：当前画布导出为图或 PDF；窗口可钉在其它软件之上，方便一边画图一边看参考（在路线里，时间未定）。
- **两人都装了 DeckRef 时**：或许会用某种有趣的方式支持互相查看对方排好的画板和便签，目前还没想好怎么实现；总之不需要联网，尽量轻量化。

以上都会按「直觉 + 本地 + 文件夹即画布」的方向做，具体节奏见 [docs/PRODUCT_ROADMAP_0.3.md](docs/PRODUCT_ROADMAP_0.3.md)。

## 我们知道的不足

- **没有协作**：单机本地用，没有多人、没有云端同步。
- **没有手绘/标注**：画布上暂时不能画箭头、圈圈，只能摆图与便签（便签计划中）。
- **多画布/多板**：目前是「一个目录 = 一块画布」，多项目多板同屏还没做，在后续版本里考虑。
- **平台差异**：灵感模式「最近使用的文件」、部分拖放与窗口行为在 Windows 上更完整；Mac 上可用，但部分能力会走简化路径。

如果你有特别在意的痛点或想法，欢迎提 Issue 或 PR。
