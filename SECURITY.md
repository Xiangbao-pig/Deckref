# Security Policy

## Supported Versions

We release security updates for the latest stable version. Please run `cargo update` and rebuild to get patched dependencies.

## Reporting a Vulnerability

If you find a security vulnerability, **please do not open a public issue.**

- **Email**: Report to the repository owner privately (e.g. via GitHub profile contact or the email you use for commits).
- Describe the issue and steps to reproduce. We will respond and coordinate a fix and disclosure.

Thank you for helping keep DeckRef and its users safe.
